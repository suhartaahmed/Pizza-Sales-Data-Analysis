# 🍕 Pizza Sales Analysis | SQL Project

## 📌 Project Overview

A Business Intelligence project focused on analyzing pizza sales data using **PostgreSQL** to identify sales trends, evaluate product performance, and generate actionable business insights.

## 🛠️ Tools & Technologies
- **Database:** PostgreSQL
- **Language:** SQL
- **Reporting:** PDF Analysis & Presentation

## 📊 SQL Analysis & Business Questions

The analysis is organized into three levels of SQL complexity:

### 🟢 Basic Analysis
- Total orders and revenue
- Highest-priced pizza
- Most popular pizza size
- Top 5 pizzas by quantity ordered

### 🟡 Intermediate Analysis
- Quantity sold by pizza category
- Hourly order distribution
- Category-wise sales distribution
- Average pizzas ordered per day
- Top 3 pizzas by revenue

### 🔴 Advanced Analysis
- Revenue contribution by pizza type (%)
- Cumulative revenue over time
- Top 3 revenue-generating pizzas per category
